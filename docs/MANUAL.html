Support Optimizer

A tool for turning a molecular structure — or any mesh — into something ready to 3D print: it builds the surface from a protein or opens your 3D file, fills empty spaces closed off inside it, turns it so it needs the least support, and saves a file with its colors for your slicer.

.pdb / .cif / .stl / .3mf Runs entirely on your machine Desktop app or browser

Open the browser version at erikeppinger.github.io/support-optimizer, or install the desktop app for Windows, macOS or Linux from the Releases page. Both work the same; the desktop app adds a Save As dialog for exports.

Overview

What the tool does, end to end.

Molecular structures — proteins, viral capsids, DNA — make striking 3D prints, but the data isn't ready to print as it is. The atoms have to become a solid surface; empty spaces closed off inside it would be printed hollow, with support trapped inside; and the way a structure happens to lie in its file is rarely the way that needs the least support. Support Optimizer takes care of all three in one place, then saves a file your slicer can print.

The five numbered sections of the app's panel match the five steps below, and the Reference part of this manual follows the same order, so you can go straight from a control to its explanation.

10-Minute Tutorial

One full pass through the pipeline, using SARS-CoV-2 main protease (PDB ID 6LU7) as a concrete example. Any structure works the same way.

1
Load a structure
Section 1 · Fetch from RCSB by ID

Type 6LU7 into the ID field and click Fetch. (Under All settings you can also choose the file format and what to download; the defaults are right here.) The app downloads the structure and builds its molecular surface — the same kind of surface PyMOL and ChimeraX show. The status line at the top shows the progress; a structure this size takes a few seconds.

Water is left out automatically. If the file contains ligands or ions, they're listed under Ligands & ions found once loading finishes, all included. Uncheck any you don't want printed and click Apply.

2
Look around
Section 2 · Scale & view

Drag in the view to turn the model, scroll to zoom. Pull the Cross-section slider partway to cut the model open on screen and look inside — the quickest way to see whether it has empty spaces inside. Double-click the slider or click Reset when you're done.

3
Find and fill cavities
Section 3 · Voids & cavities

Click Find cavities. The list shows every cavity — an empty space closed off on all sides inside the model — each checked for filling and highlighted on the model (magenta = will fill, orange = left open). The slicer would print each one as a hollow space, and any support it puts inside could never be removed. Then click Fill selected cavities. Grooves and pockets you can see from outside aren't cavities and stay as they are.

Under All settings you can also look for tunnels: narrow channels open to the outside, often where two chains meet. None are selected, since filling one changes the model's shape; check only the ones you want closed.

4
Optimize the orientation
Section 4 · Optimize orientation

Click Optimize orientation. The app tries dozens of orientations and picks the one that needs the least support — you'll see the model turn and the red areas (needs support) shrink. A model printed in several colors can instead be turned for the fewest color changes, under Optimize for. For a large model, the search runs on a simplified copy so it doesn't take long; the result is applied to your full model.

5
See what changed
Section 4 · Show support paths / Compare to start model

Under All settings, turn on Compare to start model to see the model as you loaded it next to the optimized one, and Show support paths for a rough picture of where supports would go. Together they show quickly whether the new orientation helped.

6
Export
Section 5 · Export STL / Export 3MF

Click Export STL for a single-color print, or Export 3MF to print each chain in its own filament: the slicer opens the 3MF as one part with each chain's color on its own extruder. Both files are saved as one closed solid, so the slicer doesn't report open edges. In the desktop app you choose where the file goes.

Worth knowing

Scale, Optimize and Fill can each be taken back with Undo last change at the top of the panel — but only one step, not a full history. If you're trying things out, export a copy of anything you might want to compare against later.

General controls

Controls that apply to everything: three above the numbered sections, and two icons in the lower-right corner.

Quick start / All settings

A switch at the top of the panel, also offered the first time you open the app. Quick start shows the main buttons for each step, with good defaults — enough for most prints. All settings shows every control described in this manual. The selected button and a line along the top of the panel are orange for Quick start and blue for All settings.

Switching only shows or hides controls; it never changes a setting. Quick start hides: the surface detail, file format and download choice; the chain and ligand filters; scaling by percentage or along one axis, and the chain palette; the detection setting, the cavity size limit, the highlights and everything for tunnels; the overhang angle, the simplified-copy option, the support preview and the comparison; and raising the base and the color-through option for 3MF. Two things work a little differently in Quick start: you set the print size as the model's longest side in mm, and for a large model the orientation is searched on a simplified copy automatically. Optimize for shows only when the model has several colors. In Quick start, each step's help ends with a pointer to All settings.

The choice is remembered on this computer.

Undo last change

Takes back the last Scale, Optimize or Fill, so the model is exactly as it was before. One step only, not a full history. Chain colors come back too, if that step had changed them.

Colorblind-safe colors

Switches every color that carries meaning to colors that stay easy to tell apart with color blindness:

  • Chain colors switch to the Tol Muted palette (and back to Default when turned off). If you picked a palette yourself under Scale & view, it's kept.
  • Overhang shading becomes blue / vermillion instead of blue / red.
  • Cavity highlights become bluish green (will fill) / orange (excluded).
  • Axis arrows become orange / reddish purple / sky blue.

The change shows right away and stays on for anything you load next. Colors from an imported 3MF are the file's own and stay as they are — only the overhang marking changes. The Quick start / All settings colors, orange and blue, stay apart with every common kind of color blindness, and the selected button is also shown in bold.

How it works: chain colors use Tol Muted rather than Okabe–Ito because Okabe–Ito's vermillion is also the overhang color, which would make a sixth chain look like "needs support."

About and GitHub icons (lower-right corner)

The ⓘ button opens the welcome dialog: what the tool does, a four-step quick start, what's new in recent versions, and links to this manual, the desktop downloads and the source code. It opens by itself the first time you use the tool and once after each update. The GitHub icon opens the source code; the version number sits beside both.

1

Load model

Getting a structure or mesh into the viewer.

PDB/mmCIF surface detail

How fine the surface of a protein (.pdb or .cif file) is built. Higher shows more detail, such as small grooves, but takes longer to load. STL and 3MF files are loaded as they are and don't use this.

Auto (the default) uses less detail for very large structures — hundreds of thousands of atoms — so loading stays fast. Pick a fixed value to get the same detail for every structure, or more detail than Auto would choose.

Browse for a file…

Loads a local .stl, .pdb, .cif, or .3mf file. You can also just drag a file anywhere onto the viewport.

A 3MF keeps its own colors. They're read either from standard 3MF color groups or from the per-triangle paint data PrusaSlicer, Bambu Studio and OrcaSlicer use — which is also how ChimeraX-Save3MF stores each chain's color. Triangles a slicer's paint tool subdivided more finely than one color per triangle can't be decoded and show as gray.

Fetch from RCSB by ID

Type a PDB ID (for example 6LU7) to download the structure straight from the RCSB Protein Data Bank — no account needed. The file is only kept in memory, never saved to your disk.

  • mmCIF is the current file format and works for structures of any size. Use it unless you have a reason not to.
  • PDB (legacy) is the older format: fine for small and medium structures, but very large ones may be cut short or not offered in it.

Structure content

  • Biological assembly (default) is the complete molecule as it works in nature — what the RCSB web page shows. Many entries are stored as one copy of a repeating piece, even when the real protein is made of two, three or more copies; this downloads the complete version. Copies of the same chain are named A, A-2, A-3, so each still gets its own color.
  • Asymmetric unit is the file exactly as the researchers deposited it, without the copies added. Pick it if that is what you want, or if an entry has no assembly.

If a structure looks smaller or is missing subunits compared to the RCSB page, this setting is why.

Build surface from

Appears after a protein with several chains loads. Builds the model from one chain only — to print one piece of a large complex. Nothing is downloaded again. Choose "All chains" and Apply to go back. Any Fill or Optimize you did is lost, since the surface is built anew.

Ligands & ions found

Appears after a protein loads, if the file contains anything besides the protein chains: ligands, metal ions, or leftovers from the experiment such as salts, glycerol or PEG. Each is listed with its atom count, all included by default. Uncheck what you don't want in the print and click Apply; the chain choice above is kept.

A ligand bound in a pocket of the protein usually prints fine either way. This list matters most for a loose ion or additive sitting apart from the protein, which would print as a tiny separate piece.

Water is never listed — crystallographic water is always left out, because each water molecule would become a separate speck in the print.

2

Scale & view

Sizing the model and looking at it.

Scale model

Makes the model bigger or smaller. It always scales evenly in all directions, so the proportions never change. By percentage: 200% makes it twice as large. To target size: type the size you want in mm, for the longest side or for X, Y or Z.

Cross-section

Cuts the model open on screen, along its X axis, so you can look inside it. It only changes the view, never the model. Double-click the slider, or click Reset, to switch it off.

Show subunit colors

Available once a protein with several chains (or a colored 3MF) is loaded. Gives each chain its own color, so you can see where one ends and the next begins; a legend lists each chain. These are the colors the 3MF export prints.

Surfaces that need support still show in red in this view. When Fill closes a cavity, the filling takes the color of the nearest chain.

How it works: each chain is built as its own surface during loading, so the borders between colors follow the real chain borders exactly.

Palette

The set of colors the chains use. Switching only changes the colors, right away.

  • Default — 12 colors, chosen to avoid the overhang red and blue.
  • Okabe–Ito and Tol Muted — standard colorblind-safe palettes (7 and 9 colors).
  • Viridis — strictly meant for ordered data rather than categories, but colorblind-safe and readable in grayscale, so it's offered too.

A structure with more chains than the palette has colors repeats them. Not available for a 3MF import, whose colors come from the file rather than from chain identity.

3

Voids & cavities

Finding and closing interior empty space, before it becomes trapped support material.

A cavity is an empty space closed off on all sides inside the model. You can't see it from outside, but the slicer prints it as a hollow space with walls of its own, and any support it puts inside can never be removed. A tunnel is a narrow channel through the model that is open to the outside, most often along the seam where two chains meet but don't quite close. Grooves and pockets open to the surface are neither — they are part of the model's shape and are never listed.

Very small cavities inside a single chain are found too, whatever the detection setting. Large structures can have dozens to hundreds of cavities; the list shows the 20 largest and counts the rest below them, and those are filled too.

Cavities and tunnels each have their own Find button, list and Fill button. Finding one kind leaves the other list and its selection untouched.

How it works: the model is divided into a grid of small cubes (voxels), and the empty cubes that can be reached from outside are marked. Empty cubes that can't be reached are cavities; reachable ones inside the model's outline are tunnels. Everything inside the model's surface counts as solid first — the way a slicer merges overlapping parts — so the space where chains overlap is never listed. A cavity inside one chain also has its own closed inner surface in the mesh, which is how cavities smaller than a grid cube are found (down to an eighth of one).

Void detection resolution

How small a cavity can be and still be found. Higher finds smaller and narrower cavities, and the filling follows their shape more closely, but it takes longer. Medium suits most prints.

It also matters for large prints. A cavity joined to the outside only by a very narrow slit counts as closed, and filling it closes the slit as well. At Medium, slits narrower than about 1/64 of the model's longest side count as closed; at High, 1/128. So for a large print, a higher setting keeps more of the surface's fine detail open.

Cavities

Every cavity found is checked for filling. Turn on Custom auto-select size limit to check only cavities up to a size you choose — for example to leave large cavities open. You can still check or uncheck each cavity in the list yourself.

Fill selected cavities

Makes the selected cavities solid, so the slicer doesn't print hollow spaces inside your model. The outside of the model stays exactly as it is.

A cavity inside a single chain is simply closed up. A cavity between two chains gets a small filler piece that reaches a little into the walls around it, so the slicer joins it to the model instead of printing it as a loose plug. Thin empty gaps the filler would trap next to the outer wall are filled too. A very small cavity right under the outer surface has nothing to hold on to and is skipped.

How it works

A cavity inside a chain is bounded by a closed inner surface in the mesh; Fill removes that surface, so the cavity becomes solid with nothing added. A cavity between chains has no surface of its own, and gets a filler piece built from its grid cubes. The filler reaches about 2 grid cubes into the solid around it, but only into material at least 2 cubes from the open outside, so it stays clear of the outer surface. Where that makes it stop short under a thin outer wall, it can close in a thin empty gap next to the wall; Fill checks around each filler on a grid six times finer and fills those gaps too. Bits of overlap that would end up cut off from the rest of the filler are left out, so nothing exports as a loose speck.

Tunnels

Narrow channels open to the outside. None are selected — filling a tunnel changes the model's shape more than filling a cavity, so check only the ones you want closed.

Fill selected tunnels

Fills each selected tunnel; the outside stays as it is. Unlike a cavity filler, a tunnel filler keeps a small gap to the tunnel's walls, so the slicer may print it as a separate plug inside the channel. A tunnel narrower than about 3 grid cubes is skipped — raise the detection setting and find tunnels again to fill it.

Oversized voids are refused

Each list shows a cavity's or tunnel's size as a share of the model. A "tunnel" can sometimes be all the open space between several distant chains rather than a small gap — filling that would add a piece about the size of the model. Fill refuses anything at or above 20% of the model's volume, says why, and marks it in the list.

Highlight on model

Shows the cavities and tunnels inside the model: magenta ones will be filled, orange ones are left as they are (green / orange with colorblind-safe colors on). The model turns see-through so you can see them. The 20 largest of each are shown.

4

Optimize orientation

Turning the model so it needs the least support.

Critical overhang angle

How steep an overhang your printer can print without support. A surface that leans further than this from vertical needs support and shows in red. 0° is a vertical wall; 90° is a flat ceiling facing down. Most FDM printers manage about 45°, resin printers often more. Everything in this step uses this angle: what Optimize minimizes, and where the support preview starts.

Lower angles take longer. More surfaces count as overhangs, and each has to be checked — on a test sphere, 30° took about twice as long as 45°, and 15° about three times as long.

How it works: each triangle's lean is

lean° = asin(clamp(−normalZ, −1, 1)) × 180/π

Optimize orientation

Turns the model so it needs as little support as possible — or, for a print in several colors, as few color changes as you chose under Optimize for. Undo takes it back. You can rotate the view while it runs; rotating with the mouse only changes the view, never the model.

How it works: about 38 directions are tried — 32 spread evenly over a sphere (a Fibonacci sphere), turned randomly on each run so the result doesn't depend on how the structure lies in its file, plus the 6 axis directions, where molecular and mechanical parts often rest best. The best few are refined, and the best one wins. Each is scored by

cost = Σ over overhang triangles of area × (drop height to the plate, or to whatever surface is below it first)

minus a bonus for contact with the plate (weighted at about 15% of the model's radius), so a stable, flat rest beats balancing on a corner.

Search on a simplified copy (faster)

Makes Optimize much faster on detailed models by searching for the best orientation on a simplified copy. The result is then applied to your full model, which isn't simplified — only the search uses the copy. The app suggests it for models above 20,000 triangles, and Quick start uses it automatically for them. Coarse is fastest; Fine is closest to your model.

How it works: the search time grows with the square of the number of triangles: a 200,000-triangle model would take about 4×1010 steps for each direction tried. The copy is rebuilt from a grid of 24–48 cubes per side. The result is only a rotation, so applying it to the full model loses nothing.

Optimize for

What Optimize turns the model for, when it prints in several colors — one per chain, or a colored 3MF.

  • Least support (default) turns it so it needs the least support material.
  • Fewest tool changes turns it so the printer switches colors as rarely as possible, which saves time and purged filament. Support only decides between otherwise equal choices.
  • Balanced weighs both equally.

Every layer prints each color it contains, so color changes add up layer by layer, and the orientation matters a lot: on test models the count differed by up to about three times between orientations. The status line after Optimize shows the count before and after. With a single color there is nothing to change, and Optimize goes for least support.

How it works: changes are counted for 0.2 mm layers: a layer with k colors needs k − 1 changes, one more when it doesn't contain the color the layer below ended on. On 12 test orientations of four models, this matched PrusaSlicer's count within 3%, and OrcaSlicer and Bambu Studio counted the same as PrusaSlicer. For Balanced, both are scaled to the range seen across the orientations tried, then added.

What a change costs

A tool changer like the Prusa XL swaps toolheads in seconds. A single-nozzle system like Bambu's AMS or Prusa's MMU3 unloads, loads and purges filament every time. On a four-chain test model sliced for a Bambu A1, the orientation with fewest changes cut them from 1,147 to 603, the purged filament from 392 g to 261 g, and the estimated print time by 14 hours.

Show support paths · Style

Draws a rough picture of where supports would go, to compare orientations. It isn't what your slicer will make, and it is never exported.

  • Organic (tree-like) — branches that join into fewer trunks toward the plate, like tree supports. Branches never lean further than the overhang angle, since they have to be printable too.
  • Snug — straight columns that follow the overhang's shape.
  • Grid — straight columns on a regular grid.

It runs in the background, so the app stays responsive; it is skipped for models above 3,000,000 triangles.

How it works: overhanging triangles are grouped into starting points, and each is traced straight down to the plate or to the part of the model below it.

Compare to start model

Shows the model as you loaded it next to the current one, so you can see what changed — everything since loading, not only the last step. Undo doesn't change this copy; loading a new model resets it. Together with the support preview, it shows how much support the new orientation saves.

5

Export

Saving a file your slicer can print.

Exports use the model's orientation from Optimize. Rotating the view with the mouse doesn't change what is saved. The desktop app asks where to save; in a browser, the file goes to your usual downloads folder.

Raise base to Z

Raises the exported model so its lowest point sits at this height instead of on the plate — for printing a separate breakaway support or interface layer below it. Only the saved file is raised; the model on screen stays on the plate. Preview shows the raise on screen first. Many slicers drop a loaded model back onto the plate anyway; check your slicer if the height doesn't stick.

Export STL

Saves the model as an STL file, which any slicer can open. STL has no colors; for a print in several colors, use Export 3MF. The file is saved as one closed solid, so the slicer doesn't report open edges.

How it works: inside the app, every triangle keeps its own copy of its corners. The export joins triangles at their shared corners (welding), which is what makes a slicer see one closed solid.

Export 3MF (multi-material)

Saves the model with its colors, for printing in several colors. Each color goes to its own extruder: the first color to extruder 1, the second to extruder 2, and so on — you can change that in the slicer. The slicer opens it as one part, with no open edges.

The colors are what you see: one per chain when subunit colors show, or the two overhang colors when those show. A 3MF you imported keeps its own colors. Up to 15 colors work this way; with more, each color is saved as a separate part, and the slicer reports open edges where they meet.

In OrcaSlicer, set up at least as many filaments as the model has colors before opening the file — colors beyond the number of filaments are lost when it loads. Bambu Studio says the file has an invalid configuration and loads only the geometry; the colors still come through.

How it works: the colors are painted onto one mesh, the same way PrusaSlicer's, Bambu Studio's and OrcaSlicer's own multi-material paint tools do it.

Color each chain all the way through (PrusaSlicer)

On by default. Keeps each chain one color all the way through, inside and out. Without it, PrusaSlicer with Prusa's profiles for the MK4/MK4S, Core One and XL prints the inside of thick chains in another color, with extra walls around it — in the sliced preview, chains whose inside doesn't match their outside. On a four-chain test model sliced for the XL, this cut the printed walls by more than a third.

It applies only to this model, and you can still change it in PrusaSlicer. Other slicers ignore it: OrcaSlicer colors chains through already, and in Bambu Studio, if a chain's inside comes out in another color, look for the setting named below.

How it works: the file sets PrusaSlicer's Maximum width of a segmented region (Print Settings → Multiple Extruders → Advanced) to 0 for this model. PrusaSlicer's own default is 0, no limit, but Prusa's profiles for those printers set it to 5 mm; deeper than that, a chain's inside becomes a separate region. Only for colored exports of up to 15 colors.

Concepts

The technical background behind the controls, for anyone curious what they actually compute.

Solvent Excluded Surface (SES)
The molecular surface this app builds from a PDB/mmCIF import — the same kind PyMOL and ChimeraX render by default. Computed via a two-pass Euclidean distance transform over a voxelized union of atomic spheres, offset by a solvent probe radius (1.4Å, water, by default): roughly, the surface a water molecule would trace rolling across the structure, which smooths over the small gaps between adjacent atoms that a raw van der Waals surface would leave as sharp reentrant crevices.
Heteroatoms
Atoms in a structure file that aren't part of the protein or nucleic-acid chains themselves: bound ligands, metal ions, and molecules left over from crystallization. Water is the most common by far and is always excluded here; the rest are listed under Ligands & ions found for you to keep or drop.
Marching cubes
The algorithm that turns a voxel grid (values at a regular 3D lattice of points) into an actual triangle mesh, by looking at each small cube of 8 neighboring grid points at a time and triangulating however the solid/empty boundary passes through it. Used both for building the initial surface and for remeshing small void components when sealing them.
Voxel grid resolution
How finely a shape gets rasterized before marching cubes or flood-fill runs over it — expressed as the voxel count along the model's longest axis. Higher resolution resolves finer detail (thinner walls, smaller pockets) at the cost of roughly cubic growth in compute and memory; every resolution control in the app exists because there's a real detail/speed tradeoff being made, not an arbitrary default.
Cavity vs. tunnel
Both are "voids" — disconnected pockets of empty space a flood-fill finds inside the model. A cavity is one the flood-fill can never escape from (fully enclosed); a tunnel is one it can (an open channel to the outside somewhere). See Voids & cavities for how each gets handled.
Seal overlap
How far a cavity's seal reaches into the solid around it (about 2 detection voxels), so the slicer fuses seal and walls into one solid. It never grows into material within 2 voxels of the open outside, which keeps it clear of the outer surface. Tunnels are the exception: their seals are pulled back one voxel from the walls and aren't fused with them. See the callout under Fill selected cavities.
Orientation cost
The single number Optimize minimizes: total overhang area weighted by how far each overhang triangle would have to drop before something (the plate, or another part of the model) is underneath it, minus a term rewarding a larger flat contact area with the plate. Lower is better; it's not a physical unit like grams of support material, just a consistent way to rank orientations against each other.
Support paths
A rough, illustrative sketch of where supports would likely go — not a real slicer's support generator. Real tools (PrusaSlicer's Organic supports, Cura's Tree supports) do full collision avoidance against the model as branches grow and are tuned against real print behavior; this view exists to compare relative support burden between two orientations at a glance, not to be printed from directly.

Tips & Best Practices

Working with very large structures

Leave the surface detail on Auto, and let Optimize search on a simplified copy (Quick start does this by itself; the app suggests it past about 20,000 triangles). Both keep the slowest calculations off the full model, without changing the model you export.

While a long step runs, the status line shows roughly how much time is left, once the step is far enough along to estimate it. A low critical overhang angle makes Optimize noticeably slower (see Critical overhang angle).

Small floating pieces in the slicer

Look at Ligands & ions found in section 1: a loose ion or crystallization additive sitting apart from the structure prints as its own tiny fragment. Uncheck it and Apply. (Water, the most common cause, is already excluded.)

A small hollow left after Fill

Two kinds of empty space can remain after Fill selected cavities. Thin gaps between touching chains, too thin for the detection grid to see, are left on purpose: they print as a clear edge between subunits. And rarely, filling a cavity closes the wide opening of a chamber next to it that is still joined to the outside by a slit thinner than one print layer. The slicer then prints that chamber as a small hollow — in tests on 11 structures, one such hollow of about 19 mm³ remained, in a 100 mm print. Neither is a loose piece; both print as a hollow with walls of their own.

If a tunnel gets skipped

Tunnels narrower than about three grid cubes are skipped. Raise Void detection resolution a step or two and click Find tunnels again.

FAQ

Does any of my data leave my computer?

No, except the structure fetch itself when you use "Fetch from RCSB by ID" — that's a direct download from files.rcsb.org, the same request your own browser would make visiting the URL. A locally loaded file never leaves your machine, and nothing about your session is saved anywhere once you close the app.

My slicer says the exported file has open edges — is something wrong?

Unlikely — see Export STL. Exports are saved as one closed solid to avoid exactly this, but a slicer can still be strict about very thin, sharp features. If it persists, try a higher surface detail or detection setting. A 3MF with more than 15 colors is the exception: it's saved as one part per color, and the borders between parts are open (see Export 3MF).

Why didn't Fill change how the model looks?

By design — Fill only adds material inside cavities and tunnels and never changes the outside. The change is real (see the status message after filling), but you can only see it with the cross-section.

Optimize picked an orientation that still shows red (overhang) triangles — is that a bug?

No — the search minimizes total weighted overhang cost across the whole model, not the count of overhung triangles. An orientation with a few small, low, unavoidable overhangs can beat one with zero overhangs but poor plate contact (see the cost formula under Optimize orientation), since a real print also needs to sit stably on the bed.

A tunnel I found is enormous — should I fill it?

Usually not, and above 20% of the model's volume the app won't let you. A tunnel is any empty space reachable from outside within the model's outline, so a single "tunnel" can be all the open space between several distant chains rather than a small gap. A narrow tunnel at a seam is often worth filling; a huge one usually isn't.

I loaded a 3MF and it's all gray.

The file either has no color information, or stores it as paint data a slicer subdivided more finely than one color per triangle, which this app can't decode. Files from ChimeraX-Save3MF and 3MFs with standard color groups load in their own colors.

The colorblind-safe option didn't change my 3MF's colors.

By design: a 3MF's colors are the file's own and represent what will be printed, so they're left alone. Only the overhang marking switches.
